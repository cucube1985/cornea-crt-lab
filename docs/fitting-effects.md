# 초기 피팅의 접촉선 힘과 착용 후 실측 비교

이 기능은 교육·환자 설명을 위한 계산입니다. 표면장력으로 교정 도수, 안정성 또는 고착을 예측하지 않습니다. 실제 환자 자료는 이 문서나 저장소에 포함하지 않습니다.

## 1. 표면장력 성분

렌즈 바깥 둘레 전체에 하나의 원형 접촉선이 있고 그 선 전체가 젖었다고 가정합니다. 접촉선 직경 D를 OAD와 같게 놓습니다. 각막 쪽 축과 표면장력의 접선 방향 사이 각도를 β로 정의하면, 원주를 따라 적분한 축방향 성분은 다음과 같습니다.

`Fz [mN] = γ [mN/m] × πD [mm] × cos(β) / 1000`

- 초기 γ=40 mN/m, β=30°는 환자 측정값이나 정상 기준이 아닌 설명용 가정입니다.
- β는 축방향에 대한 투영각입니다. 재질의 젖음 접촉각이나 LZA를 대신 입력하는 칸이 아닙니다.
- 한 접촉선만 계산합니다. 두 눈물 표면을 이유로 계수 2를 곱하지 않습니다.
- 10.5 mm에서 약 1.143 mN, 11.0 mm에서 약 1.197 mN입니다. 두 값은 초기 가정에 한정됩니다.
- 동일 D·γ·β에서 BC/RZD/LZA를 바꿔도 이 성분은 같습니다. 간격으로 β나 압력을 추정하지 않습니다.
- 3D 화살표는 각막 쪽 축방향 성분의 방향만 나타냅니다. 길이는 수량을 나타내지 않으며, 분리 보기에서는 렌즈와 함께 이동합니다.
- 표면 간섭 또는 각막 경계 밖 영역이 있는 경우 적용할 수 없는 산술값임을 표시하고 화살표를 생략합니다. γ=0 또는 β=90°에서도 화살표를 표시하지 않습니다.

총 유지력에는 압력의 면적 적분, 눈꺼풀 하중, 접촉·마찰, 운동과 박리 조건 등이 필요합니다. 현재 모델은 이 항들을 풀거나 실제 제거력을 측정하지 않습니다. 표면장력 수치를 임상적으로 적절한 범위로 판정하지 않습니다.

근거: [Athukorallage와 Iyer, Model of a Contact Lens and Tear Layer at Static Equilibrium (2013), 식 38–40](https://www.math.ttu.edu/~rvenkata/Papers/Bhagya_ACC_2013.pdf). 접촉선 힘을 접선 벡터로 적분하고 다른 하중과 함께 평형을 구성하는 논문입니다. 앱의 식은 그 접촉선 적분에 일정 γ·원형 직경·일정 투영각을 적용한 단순화이며 논문의 전체 평형 모델을 구현한 것이 아닙니다.

## 2. 실제 교정 비교

Advanced에서 같은 환자·같은 눈의 전후 검사값을 수기로 입력합니다. 측정한 눈과 현재 모델의 OD/OS가 다르면 결과와 적용 기능을 숨깁니다.

| 지표 | 계산과 의미 |
| --- | --- |
| 구면 S, 원주 C, 난시 축 | 전후 입력값 그대로 나란히 표시. C는 ±표기 모두 허용 |
| 구면등가 SE | S+C/2. S와 C 모두 필요하며 난시가 없으면 확인 후 C=0 입력 |
| SE 변화 | 후 SE−전 SE. 근시안에서 양수는 근시 감소 방향 |
| 평균 K | (Flat K+Steep K)/2. 각 시점의 두 값 모두 필요 |
| 평균 K 감소 | 전 평균 K−후 평균 K. 양수는 입력 K의 평탄화 |
| 치료 영역 직경 | 착용 후 Topo에서 평가한 영역. BC 직경과 별개 |

누락값은 0으로 대체하지 않습니다. 검사 방법·정점거리·동일 장비/Topo 평가 구역·조명·렌즈 제거 후 시간을 맞춰 해석합니다. 날짜, 착용 기간, 제거 후 측정까지 시간과 조건 메모를 함께 보관할 수 있습니다. 평균 K 감소와 SE 변화는 서로 다른 측정 지표입니다. AXL은 기존 기록용 항목이며 이 비교로 근시 진행 억제 효과를 계산하지 않습니다.

직경만 입력한 치료 영역은 직경 도식만 표시합니다. 중심을 미측정한 상태에서 중앙 정렬이나 동공 겹침을 가정하지 않습니다. 정점 기준 정면 관찰자 좌표(+X 오른쪽, +Y 위쪽) 중심을 모두 입력하면 현재 입력된 동공과의 원형 평면 겹침을 계산합니다. 동공은 현재 모델의 입력 조건이며 별도의 착용 후 실측이라고 가정하지 않습니다. 3D 반영 범위는 직경 1~8 mm, 중심 ±2 mm입니다. 수치 기록 범위는 직경 1~9 mm, 중심 ±3 mm입니다.

선택 기능인 전후 K 근사 모델은 A/B 슬롯을 교체합니다. 네 K가 모두 35~55 D이어야 하며, 각 시점의 K/Topo 축을 사용하고 미입력 축은 90°로 가정합니다. 두 모델 모두 Q=−0.25, 주변부 Sag 미지정, 비대칭 0으로 초기화합니다. 현재 렌즈·각막 크기·동공 등 나머지 조건은 유지됩니다. 착용 전 주변부 실측을 착용 후 표면에 이식하지 않습니다. 치료 영역 원을 표시해도 국소 평탄화나 상피 변화를 재구성하지 않습니다. 실제 전체 Topo 차이지도는 아닙니다.

관련 실측 연구: [Kim 등 (2018), Corneal epithelial and stromal thickness changes in myopic orthokeratology and their relationship with refractive change](https://pmc.ncbi.nlm.nih.gov/articles/PMC6155449/). 이 연구를 개인별 교정량 예측 공식으로 사용하지 않습니다.

## 저장과 검증

입력값은 브라우저 메모리에서만 처리합니다. 선택한 경우에만 기기 보관 또는 JSON 내보내기를 사용하며 서버나 GitHub로 전송하지 않습니다. 기존 version 2 설정은 새 항목에 기본값/빈 측정값을 적용해 계속 불러옵니다. A/B 슬롯에는 당시 입력값의 복사본을 보관합니다.

`effects-tests.mjs`는 독립 SI 단위 환산, 두 직경과 각도 경계, SE/평균 K 산술, 누락·우안/좌안 불일치, 잘못된 범위/날짜, 기존 설정 호환성, JSON 왕복, K 근사 모델의 주변부 초기화와 누락 중심 처리 등을 확인합니다. 수치 테스트는 임상 검증을 의미하지 않습니다.
