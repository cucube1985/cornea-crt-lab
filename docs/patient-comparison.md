# 환자별 전안부 수기 입력과 A/B 설명

이 기능은 측정한 요약 수치로 각막 근사 표면을 만들고 렌즈·동공과의 기하 관계를 비교합니다. 전체 지형도를 재구성하거나 개인별 처방/교정 결과를 예측하지 않습니다. 장비 원본 파일을 요구하지 않으며 모든 입력과 JSON 처리는 브라우저 안에서 진행합니다.

## 권장 순서

상단의 `구현 모델 선택`에서 **Advanced**를 선택합니다. Basic과 Basic-OK는 고정 가정의 단순 각막을 사용하며 아래 추가 조건을 반영하지 않습니다. OK는 렌즈 형상만 표시합니다.

1. 원래 ARK 패널에 Flat K, Steep K, Steep axis를 입력합니다.
2. `①~⑤ 조건 입력`을 열어 비교용 별칭, OD/OS, 알고 있는 조건을 입력합니다. AXL은 기록용입니다.
3. 각 항목군의 출처를 가정값/수기 입력/측정값 입력 중에서 선택합니다. 계산된 모델 수치와 실측 수치를 혼동하지 않도록 미측정 주변부 칸은 비워 둡니다.
4. `현재 모델에 적용`으로 3D·간격 지도·단면을 확인합니다.
5. `현재 → A`에 담고 다른 렌즈나 조건을 설정한 뒤 `현재 → B`에 담습니다. 조건/환자/착용 전후 중 비교 목적을 선택할 수 있습니다.
6. 정면 그림은 동일 mm 축척, 단면은 각 자료의 선택 주경선으로 비교합니다. 같은 환자의 다른 렌즈 조건을 비교하려면 두 슬롯의 각막 측정값과 조명 조건을 같게 유지합니다.
7. 비교 JSON 저장/불러오기, 비교표 인쇄를 사용할 수 있습니다. 기본은 메모리 보관이고 새로고침하면 입력이 초기화됩니다. 필요한 경우에만 `이 기기에 비교 설정 보관`을 선택합니다.

이름·차트번호 대신 비교용 별칭을 사용하세요. 공개 GitHub 저장소에는 앱 소스와 가상 예제만 포함하며 사용자 측정값을 업로드하는 기능은 없습니다.

## ① 각막 크기

HVID와 수직 직경의 단위는 mm입니다. 이 두 지름으로 표시 경계를 구성합니다. 수직 직경을 측정하지 않았다면 비워 둡니다. 이 경우 HVID와 같은 원형 경계를 가정하고, 비교표에 가정 경계로 표시합니다. HVID와 장비 WTW는 정의가 다를 수 있으므로 동일한 장비/정의로 비교합니다. 렌즈 footprint 중 이 경계 밖은 간격 계산에서 제외하며, 유효 격자 비율을 함께 표시합니다.

## ② Q/e

Flat/Steep 주경선의 값을 각각 입력합니다. 동일한 conic 정의에서만 Q = −e²로 환산하며 장비의 측정/피팅 구간을 메모할 수 있습니다. 기존 각막 패널의 공통 Q를 직접 바꾸면 주경선별 Q를 공통값으로 되돌립니다. 원래 K값은 각막 중심의 주경선 반경을 유지합니다.

## ③ 주변부 높이

**직경과 반경을 구분합니다.** Ø8 mm 위치는 정점에서 반경 4 mm, Ø10 mm 위치는 반경 5 mm입니다. 각 주경선 양쪽 값을 평균한 높이를 입력합니다. 앱은 전방을 z 양수로 놓으므로 입력하는 Sag는 아래 방향 깊이의 양수값입니다. CED는 동일 chord에서 두 주경선의 평균 Sag 차이로 파생하며 비교표에서는 절댓값도 표시합니다.

주변부는 입력한 두 주경선 평균 높이에 맞춰 매끄럽게 보정합니다. 중심의 K를 유지하도록 중심에서 보정이 완만하게 시작하고 Ø8/Ø10 mm를 연결합니다. 그 사이와 원주 전체는 보간된 근사이지 실측 표면이 아닙니다. 비어 있는 칸은 기본 모델을 사용하며 비교표에서 `모델 추정`으로 구분합니다. CED 하나만으로는 평균 높이를 결정할 수 없으므로 두 원본 높이가 없으면 억지로 채우지 않습니다.

### BFS elevation을 가지고 있는 경우

입력 종류를 BFS elevation으로 바꾸고 다음 값이 있어야 합니다.

- 같은 x/y 원점과 축을 사용하는 **중심정렬 구면 BFS의 반경**(mm)
- 그 BFS에 대한 **각막 정점 elevation**(µm)
- 각 chord의 두 주경선에서 측정한 평균 elevation(µm, 전방 양수)

변환은 `Sag(r) = sphereSag(r, BFS radius) − elevation(r) + apexElevation`입니다. 구면 BFS가 편위/기울어져 있거나 기준 정보가 없으면 이 변환으로 복원할 수 없습니다. 단순 elevation을 정점 기준 Sag 칸에 그대로 입력하지 않습니다.

가상 예시: 중심정렬 BFS 반경 8.0 mm, 정점 elevation 10 µm, Ø8 Flat/Steep elevation 0/−50 µm라면 평균 Sag는 약 1081.8/1131.8 µm이며 CED는 50 µm입니다. 0 elevation은 기준 구면과 높이가 같은 유효한 측정값입니다. 빈칸과 구분합니다.

## ④ 비대칭과 좌표

비대칭은 Ø8 mm에서 **비측−이측, 상측−하측의 전방 elevation 차이**(µm)입니다. Sag 차이를 가지고 있다면 부호가 반대입니다. 두 값은 중심 K와 두 반대편 평균 높이를 유지하는 매끄러운 비대칭 표면을 구성하는 추가 조건입니다. 반경 4 mm에서 그 차이를 맞추고 다른 반경은 3차 변화로 근사하므로 실제 주변부 전체 비대칭을 복원한 것은 아닙니다.

화면은 정면 관찰자 기준 +X 오른쪽, +Y 위쪽, 원점은 각막 정점입니다. OD의 비측은 +X, OS의 비측은 −X로 표시합니다. 좌우눈을 바꾸면 비측 방향이 바뀌며, K축과 동공 좌표를 장비에서 확인한 화면 좌표로 맞춰야 합니다. 서로 다른 눈의 지형도를 자동 영상 정합하지 않습니다.

## ⑤ 동공과 치료 영역

명소시·박명시 직경과 선택한 조명에서의 동공 중심 x/y를 입력합니다. 조명을 바꿔도 중심 이동을 자동 추정하지 않으므로 해당 조건의 좌표를 다시 입력하세요. 보라색은 각막 좌표면에 투영한 입사동공이며 각막 굴절에 의한 광학적 추적은 포함하지 않습니다.

치료 영역은 렌즈 BC 직경과 같지 않습니다. 착용 후 측정한 원형 근사 영역 또는 설명을 위한 가정 영역의 직경·중심을 별도로 입력할 때만 동공 포함 면적을 계산합니다. 미입력은 `—`이며 비교표에서 가정 영역/측정 영역을 구분합니다. 이 비율은 번짐, 수차, 시력 또는 근시 억제 효과의 예측 지표가 아닙니다.

## 해석 범위와 문헌

자동 안착은 유한 격자에서 수직 이동만으로 최소 간격을 2 µm로 만드는 수학적 배치입니다. 압력·눈물 유동·안정성·각막 변형을 계산하지 않습니다. 치료 전후 비교는 따로 입력한 자료의 비교이며 치료 후 형태를 예측한 것이 아닙니다. AXL은 표면 및 동공 겹침 계산과 분리된 기록입니다.

- [Li 등, 2018: 주변부 CED와 치료 영역 탈중심](https://pubmed.ncbi.nlm.nih.gov/29806506/): 특정 집단/렌즈에서의 연관성 연구이며 수치를 자동 처방 임계값으로 사용하지 않습니다.
- [Li 등, 2017: 사분면 Q 차이와 탈중심](https://pubmed.ncbi.nlm.nih.gov/28079814/): 비대칭을 고려하는 후보 근거이며 개인별 편위량을 확정하는 식으로 사용하지 않습니다.
- [Eltantawy 등, 2026: 좌표 정렬·간격 대칭성과 수차](https://pmc.ncbi.nlm.nih.gov/articles/PMC13369213/): 치료 후 자료와 특정 설계에 대한 연구입니다. 본 앱의 환자별 착용 전 결과 예측을 검증한 근거가 아닙니다.
- [Kim 등, 2018: CRT 상피 변화와 치료 영역](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0203652): 렌즈 BC 영역을 실제 치료 영역과 동일하게 취급하지 않는 참고 자료입니다.
